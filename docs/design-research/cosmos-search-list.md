# Cosmos search list for RCMExcel

Every term from both briefs, deduplicated, grouped by the board each should feed. Click a term to open the Cosmos search.

## How to filter (save / skip)

Save if it has: a visible grid, strong type hierarchy, real information (numbers, tables, diagrams, documents), restrained colour (navy, slate, off-white, one accent), hairline rules, editorial print feel (annual reports, journals, case studies).

Skip if it has: gradients or glowing blobs, glass or frosted panels, 3D renders, stock doctors and stethoscopes, rainbow palettes, piles of floating rounded cards, crypto or AI-startup look, pretty but empty (no information).

Tip: open an image you love, then use its Visual search (the ··· menu) and the Similar elements row. Follow the collections listed under Saved by. Colour search: the colour wheel in the search bar.
