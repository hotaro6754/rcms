# RCMExcel — Visual reference library

Research run: November 2026. Every live URL below was opened in a browser during this run unless marked otherwise. Screenshots are in `research/reference-screenshots/` (69 files). Dribbble and Behance entries are **concepts**, not live products, and are marked as such. Awards are as listed on each site's Awwwards page at the time of the run.

Priority key: **H** = shapes the direction, **M** = borrow one pattern, **L** = context or anti-reference.
